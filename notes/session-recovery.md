# 重启后的会话恢复提示

恢复批次由 Host 插件实例持有，浏览器首次查询启动异步检查，读取通过公开 `sessionQuery` 观察完成并释放租约。判断使用本会话最后一轮及事件时间，不能使用仅表示最近人类输入的列表 `updatedAt`。继承历史、主动取消、完成轮次和一次性子会话不进入候选。

浏览器使用 `sidebar.footer.action`、主题文字颜色和官方 `Button`，勾选及叉号带本地化无障碍名称。勾选前没有续作副作用。批次号拒绝旧页面写入，恢复工作单飞，每项保留请求 ID；恢复前重读最后轮次并检查运行状态及输入队列，避免重复续作。可续作子会话通过原父身份恢复，已完成的普通父会话只挂载 Agent。无法挂载的非候选子父会话保留失败提示，不创建替代会话。

忽略状态随 Host 插件实例保存，整进程重启或重新加载插件后重新检查。默认回看启动前一小时；配置允许调整范围、轮询和读取超时。当前设计不保存新的会话格式，也不将恢复接收回执解释为任务完成。

验证使用合成会话日志和真实 UI 原语：检查立即返回、多次检查共享批次、主动取消及继承过滤、重复点击、失败重试、检查后已有续作、父子身份、忽略、卸载及晚到响应。正在使用的 DSH 实例不属于合成测试数据。
